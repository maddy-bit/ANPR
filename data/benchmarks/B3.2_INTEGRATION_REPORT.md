## 1. Executive Summary

In Batch B3.2, modular, read-only ingestion loaders were designed and implemented for all three external benchmark datasets acquired in Phase B:
1. **VeRi-776** (`VeRi776Loader`): Vehicle Re-ID appearance matching, feature extraction, and camera topology calibration.
2. **UA-DETRAC** (`UaDetracLoader`): Vehicle object detection (YOLOv8s) and single-camera multi-object tracking (ByteTrack).
3. **UFPR-ALPR** (`UfprAlprLoader`): License plate bounding box detection, 4-corner polygon regression, and character-level Latin OCR.

All loaders adhere to a unified base abstraction (`BaseDatasetLoader`) in `ai-service/loaders/base.py`, featuring:
- **Strict Read-Only Enforcement**: Zero modifications, mutations, renames, or deletions of source dataset files.
- **Lazy Memory Management**: Metadata and annotations are indexed efficiently; raw image buffers are never retained in RAM.
- **Dynamic Path Resolution**: Automatic repository root discovery (`find_repo_root()`) with zero hardcoded machine-specific absolute paths.
- **Leakage Prevention & Isolation**:
  - VeRi-776 strictly quarantines all 32 orphan unannotated training images, eliminating cross-split collision with test vehicle `0402`.
  - UA-DETRAC strictly excludes the 60 training sequence directories, evaluating only the 40 test sequences.
  - UFPR-ALPR implements dual evaluation modes: an *Official Mode* (all 60 test tracks) and a *Decontaminated Mode* (58 tracks, quarantining `track0110` and `track0140`).
- **Resilient Parsing**:
  - Handles `gb18030` multi-byte XML encoding in VeRi-776.
  - Represents the 173 empty-scene frames omitted from UA-DETRAC XML as valid zero-object ground truth.
  - Dynamically queries image dimensions in UFPR-ALPR to support both $1920 \times 1080$ and $1920 \times 1088$ images without coordinate drift.

## 6. Remaining Domain Limitations & Operational Guidance

While the loaders provide mathematically clean, leakage-resistant access to the external benchmarks, the following domain-specific constraints must be maintained during Phase B evaluation:

1. **VeRi-776**:
   - Must be used **strictly for Re-ID feature extraction and spatio-temporal transition velocity calibration**.
   - Standard annotations do not contain license plate text. It must never be used for OCR evaluation.
2. **UA-DETRAC**:
   - Must be used **strictly for single-camera vehicle detection and within-camera tracking**.
   - Sequences are independent overpass captures with zero cross-camera identity linkage. It cannot evaluate cross-camera association or global trajectory reconstruction.
   - Traffic consists exclusively of 4-wheel vehicles (cars, buses, vans). It lacks two-wheelers and auto-rickshaws, which represent >70% of Indian urban traffic.
3. **UFPR-ALPR**:
   - Evaluates mobile dashcam ALPR from a moving patrol car (1.5–2.0 m viewpoint), which differs from overhead pole-mounted surveillance CCTV (5–10 m viewpoint).
   - Plate syntax follows Brazilian Mercosur formatting (3 letters + 4 digits). It validates Latin character OCR robustness under blur, glare, and tilt, but does not substitute for Indian CMVR Rule 50 license plates.
   - Benchmark evaluation results must report **both Official Split Accuracy and Decontaminated Split Accuracy** side-by-side.
